# 实验代码

本目录保存不同抽取路径、SDK 集成和硬件运行方式的研究实现。它们默认不启用，不是基础安装或离线示例的依赖。保留代码用于阅读、测试与可复现实验，不意味着这些路径在当前环境中已经通过质量或性能验收。

先阅读 [实验与评测](../docs/experiments.md)：其中给出离线合成示例、自有数据的两种评测流程、时间指标定义、推理 RSI 门槛及历史 runner 的部署限制。训练准备见 [训练文档](../docs/training.md)，合并与 W8A8 导出见 [量化文档](../docs/quantization.md)。

| 内容 | 范围 |
|---|---|
| `kev_direct/` | Kev 候选选择与主模型审核；部分 runner 依赖历史 Linux / CUDA 服务布局，不是通用启动器 |
| `ner_assisted/` | 使用已有 UIE checkpoint 生成来源绑定的实体索引，不自动训练 |
| `prepare_ppu_quantization.py` | 针对固定模型布局的 CPU 合并与 W8A8 导出；导出不代表 PPU 可加载或效果通过 |
| `ppu_runtime_audit/` 与 `ppu_*.py` | 特定加速器的运行时、吞吐和内核检查 |
| `tongagents_*.py`、`tong_sdk_*.py` | 可选 TongAgents SDK 集成探测 |
| `compare_*.py`、`summarize_*.py` | 对已有实验记录进行比较和汇总 |

实验需要的模型权重、LoRA、数据、SDK 和运行记录不随仓库发布。使用前检查脚本参数、目录约定及目标硬件能力，自行确认相应资产的许可。不得从一个硬件或数据集上的结果推导另一个环境的效果。

新增实验应固定输入、模型、tokenizer、配置和评分版本，记录失败和完整墙钟。将基线与候选放在独立运行目录，明确预热和缓存条件。实验代码或静态回放通过，不足以启用 RSI；仍需完整质量、处理速度和恢复速度验收。

最小检查可以运行 `python experiments/prepare_ppu_quantization.py --help` 或 `python experiments/ner_assisted/infer_index.py --help`。真正执行需要显式准备对应资产及独立环境；不要根据 `--help` 可运行就认为基础安装含有张量框架或硬件支持。单次生成、完整报告多任务和硬件探针使用不同协议，不应把历史结果混为本次公开版验证。

`contest/document_native_processor.py` 仅供历史运行环境的审计与适配参考，不是通用视觉解析入口。公开源码已移除私人部署身份，相关位置使用明确未配置的占位值；历史缓存重放默认拒绝运行。依赖文件哈希、路径、解释器、环境与当前服务身份校验仍然保留。公开版没有已绑定并验收的对应运行环境，适配后须重新完成真实验收，不能通过删除校验条件取得能力通过状态。
